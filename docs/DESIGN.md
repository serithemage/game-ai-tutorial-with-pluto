# Pluto 통합 HTML 튜토리얼 설계

사용자는 프로그래밍 경험이 없는 대학생을 대상으로 Pluto의 학습과 동작을 분석 보고서에 기반해 설명하는 하나의 HTML 튜토리얼을 승인했다. 학생/교사용 분리는 없앤다. 수학은 그림과 조작을 통해 설명한다. 공개 저장소 serithemage/game-ai-tutorial-with-pluto와 GitHub Pages 배포, 자체 제작 자료 CC BY 4.0을 승인했다.

## 학습 흐름
1. 게임 상황에서 관찰 → 계산 → 행동의 전체 흐름.
2. 유닛·지도·전역 정보를 숫자로 표현.
3. 가중치 조합과 실제 109→256 변환. 비선형 계산은 직관으로 설명.
4. 과거 상태와 새 정보를 섞는 기억.
5. 행동·인자·대상과 게임 연결 프로그램.
6. 자기 대전 → 경험 평가 → 모델 조정. 정확한 Pluto 훈련 수식은 미확인.
7. 학습/추론/양자화/별도 오프닝 선택의 구분.

## 표현과 동작
- 하나의 본문, 목차, 펼칠 수 있는 분석 근거, 마지막 이해 확인.
- 그림은 직접 만든 SVG와 CSS로 구성. 실제 StarCraft 스크린샷 또는 로고를 사용하지 않는다.
- 가중치와 기억 비율 조작은 교육용 모형. 본문은 JavaScript가 없어도 읽힌다.
- 실제 정적 관찰, 일반 원리, 공개 설명을 문맥에서 구분한다.
- 화면은 밝은 청회색(#f7f9fd), 흰색(#ffffff), 남색(#23395b), 청록(#197d91), 금색(#c58732). 제목은 한국어 고딕 굵은 글자, 본문은 편안한 고딕. 게임판과 신호 흐름이 주 시각 요소다.
- PC는 옆 목차와 한 열 본문, 모바일은 위 목차와 본문. 키보드 조작, 보이는 포커스, reduced-motion, 충분한 대비를 지원한다.

## 파일과 배포
- tutorial/index.html, styles.css, app.js, learning.mjs가 단일 교재다.
- scripts/build_site.mjs는 _site/로 교재, HTML 분석 보고서, 인용 근거, 라이선스를 복사한다.
- 원본 바이너리, 로컬 도구, 민감한 사용자 설정 진단, 제공자 캐시는 공개하지 않는다.
- GitHub Actions Pages 배포를 사용한다. LICENSE, README, 사이트 하단에 CC BY 4.0을 명시한다. 외부 자료와 역컴파일 산출물은 자체 CC 적용에서 제외하고 출처를 표시한다.

## 검증
조작 산술, 경계값, 초기화, 근거 링크, 모바일 가로 넘침, 키보드 및 이해 확인 동작을 검사한다. 공개 배포 완료와 실제 HTTP 응답을 확인한다.
